# DX-Camp Döbriach 2026

**Abgeschlossen** · Zeitraum: Vorbereitung bis zum DX-Camp vom 17. bis 26. Juli 2026

## Ziel

Beim DX-Camp in Döbriach sollte eine Remote-Station über das Web bedienbar sein. Das Minimalziel (MVP) war ein einzelnes FM-Modul für 2 m, das du über die Weboberfläche steuerst.

## Ergebnis

Die Steuerung der Station übers Web lief beim Camp. Es gab dabei **noch kein Audio**. Der Funkbetrieb mit Sprache im Browser kam erst danach, im September und Oktober 2026.

## Was das Projekt angestoßen hat

- **Eine Modul-Plattform:** Statt die Station fest auf ein bestimmtes Funkmodul zuzuschneiden, beschreiben sich die Module jetzt selbst. Das ist das Fundament für weitere Module.
- **Eine virtuelle Station:** Sie läuft in QEMU, mit demselben Linux-Image wie die echte Station, und lässt sich ohne Hardware testen.

Wie die Station heute aufgebaut ist, beschreibt die [Technik](../remote-station/).
